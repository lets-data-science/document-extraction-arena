# Document Extraction Arena — LDS build-along

**Contributor:** Dev Suthar · **Publisher:** Let's Data Science · **Version:** 1.0.1

Build an invoice evaluator whose scores you can explain. Complete safe amount normalization, one-to-one row matching and an honest score report. Start without an API key using preserved, measured responses; optionally try one Gemini extraction at the end.

Start with `README.md` for installation, or follow all seven steps in `docs/BUILD-ALONG.md`. Download the starter and reference from the [LDS GitHub release](https://github.com/lets-data-science/document-extraction-arena/releases/tag/v1.0.1) into separate directories. The accompanying LDS website guide is being reviewed separately.

The historical paired result is 11/16 versus 15/16 exact invoices on one synthetic layout. This is exploratory evidence, not a general model ranking. See `docs/METHODOLOGY.md` for date ambiguity, sample coverage, latency and cost boundaries.
